# Use it — run Rocky 10 + a stock 6.18 kernel on your DGX Spark

The primary path, and it's meant to be dead simple: try the signed Live USB (non-destructive), then install to the NVMe if and when you want it for real.

- [`running.md`](running.md) — flash a USB, boot, run one check. **Start here.**
- [`install.md`](install.md) — lay the stack down on the internal NVMe (optional, destructive).
- [`verify.md`](verify.md) — prove the image is genuinely ours before you write it.
