# docs/ — three stories

Organized by what you came to do. Pick one:

- **[`use/`](use/)** — run it on your Spark: flash a USB, boot, check, and install to the NVMe when ready. **Start here if you just want to try it.**
- **[`build/`](build/)** — how it's built and how to rebuild it from source. The kernel, driver, and config work; an OS-development project.
- **[`benchmark/`](benchmark/)** — the performance numbers, how to reproduce them, and how they compare to published results.
